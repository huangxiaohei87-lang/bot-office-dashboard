# 工程说明（第一期原型）

## 实现概要

- **外壳：** CSS 实现纸白色板（`#FEFEFE` / `#F4F2EE`），窗口圆角 18px，右侧 480px 圆角对话卡片，内缩 18px。
- **场景：** `public/assets/scene/ambient-07.png`（界面稿 `01-左侧场景氛围.png`）置于 Leafer `App` 中，视口底 `#101010`、圆角 16px；工具条在黑色容器下方的纸白壳上。
- **交互：** 平移（拖拽画布）、缩放（滚轮与 ± 按钮）；`wheel.rotateSpeed = 0` 禁止旋转。点击助理热区聚焦右侧输入框，无弹窗。
- **数据：** `src/mock-data.ts` 本地模拟，无真实 Bot/聊天 API。
