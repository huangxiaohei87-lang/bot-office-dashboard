## 本轮改了什么

只改一件事：开灯房间向黑色地面晕出的环境光，过渡要更自然。不再用整屋占用遮罩描一圈均匀、偏硬的外发光；光按窗、门、落地灯和靠开口的暖色地面布置，衰减柔和、有远近。靠近门和暖地面的一侧稍明显，背光或远离开口的一侧更弱、更短。仍然只一点点，不是舞台追光，也不是整幅暖雾。办公室名牌仍然不发光。
