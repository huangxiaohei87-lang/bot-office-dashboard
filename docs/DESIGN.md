## 1. 相机与网格

- **投影：** 标准 2:1 等轴测。菱形网格横向 2、竖向 1。
- **镜头：** **固定为西南（SW）**，看见物体的南面与西面。等价于 Kenney Furniture Kit 的 `_SW` 方向。所有房间、家具、人物、道具只画这一向。
- **禁止混向：** 不把 Furniture Kit 的 NE/NW/SE 与 Isometric Miniature 系列的 E/N/S 精灵混进同一镜头。Library / Prototype 的结构只转译进 SW。
- **画布：** 可平移、缩放；**不可自由旋转**。按个位数到十余间办公室构图，不是协同白板，也不是可轨道旋转的真 3D。
- **坐标系：** +X 为东（屏幕右上），+Y 为北（屏幕左上），+Z 向上。西南角靠近相机，位于屏幕下方。
- **切墙：** 采用面向相机的剖切（不画南墙与西墙，只保留北墙与东墙），以便看清室内。门口在南沿或西沿用门框和门垫标出；房间名用门楣或西门侧招上的灯牌标出，文字画在灯牌南向牌面上，随同一透视，不是压在图上的平面标签。

## 2. 色与材质

主气质：偏软、干净的色块轴测。浅木色、奶油墙、柔和阴影、清晰体块。不是像素网格，不是深色 SaaS 控制台，也不是营销落地页。

- 画布底：暖浅灰 `#ECE8E0`，极弱的等轴测网格。
- 开灯地面：按房间略有差别的浅木色；墙面奶油；窗玻璃偏冷青，但不刺眼。
- 关灯/空地：冷灰蓝、去饱和、明度明显降低，无灯具发光。
- 材质分面：顶面最亮并略暖，南面（右侧）为固有色，西面（左侧）略暗但仍保持墙面的奶油感，避免东墙读成灰板。
- 八岗各有不重复的柔和强调色（见 `资产/色板.png`）：助理海军蓝、构思家芥末黄、素材管理灰绿、视觉与动效珊瑚、工程钢蓝、审查闸门灰紫、上架辅助陶土、HR 尘粉。对比足够，偏办公室，不是霓虹。

## 3. 开灯 / 关灯规则

无现成成套包，在同一轴测语汇下自绘。

**开灯（已创建）：**

- 室内暖亮，木色与奶油墙明度高。
- 窗有玻璃高光，并向室内地面投下浅浅的暖窗光。
- 落地灯灯罩发暖光，地面有光斑；房间中部有吊灯及光池。
- **门楣/侧招是与建筑一体的名牌：** 干净的浅色牌面、强调色端帽、字清晰写在牌面上。界面层以 2026-11-16 01:01 为准：名牌不是发光体，不要溢光、光晕或牌面自发光。室内窗光、落地灯、吊灯的房间光照可以保留。
- 人物、家具、姓名牌清晰可辨。

**关灯（同一房间示意）：**

- 整体冷灰蓝、去饱和，明度明显更低。
- 灯具形态还在，但灯罩不发光、地面无光池。
- **关灯房间的名牌：** 同一块建筑名牌还在，牌面转冷灰，字仍可认出；同样不发光。开灯与关灯主要靠室内明暗和色温区分，不要靠光晕区分。
- 窗玻璃变暗。可留家具暗轮廓，不安排人物（对照稿如此，以免与「未创建」混淆时误读为有人在关灯房办公）。

**未创建 / 空地占位：**

- 不建房，或只保留关灯地基菱形。
- 无家具（或仅浅浅的暗轮廓）、无人物、无灯具发光。
- **没有房间名牌**，也不做空灯箱。只用一块安静的冷色地基铭牌写「未创建」，字贴在地面牌面上，不是立着的牌或发光体。

禁止把 Prototype 的 `switchFloorOn/Off`、`switchWallOn/Off` 当作办公室开灯方案。

## 4. 灯牌规则

- 房间名只用：「老大办公室 / APP制作台 / 人事部 / 茶水间」。
- 名牌是建筑的一部分：南门为门楣牌，西门为向外伸出的南向侧招，有厚度，文字透视贴在南向牌面上。不要改回压在图上的平面标签。
- **比例：** 牌面高度、厚度与字号须足够大，使四个房间名在 2400×1680 的画布总图上即可轻松读出，包括较长的「APP制作台」「老大办公室」。不要再用细长小条挤字，也不要缩回第一轮过小的尺寸。可明显大于门洞楣沿，但不得大到挡住人物、姓名牌或把门洞压垮。
- **不发光：** 界面层以本轮为准。开灯房间的名牌是干净、有正常轴测明暗的哑光牌面（浅纸白或浅象牙，近黑墨字），不是发光体，不要溢光或牌面自发光。关灯房间的名牌牌面转冷灰，同样不发光；开/关主要靠室内明暗和色温区分。对照见 `界面设计稿/02-灯牌无灯效对照.png`。已确认的 `场景设计稿/05-开灯关灯对照.png` 仍是 00:28 定稿，本轮未重渲。
- 未创建空地无房间名牌。地基「未创建」铭牌可略加强可读性，但不得做成点亮灯牌或发光体。
- 中文必须用正确简体后叠在牌面上，不得使用生成图里的汉字。长名（「老大办公室」「APP制作台」）不得裁切，也不得被灯箱端帽挡住。

## 4.1 在岗坐姿与茶水间座位

在岗朝向以 2026-11-15 23:55（Asia/Shanghai）为准；离开空椅以 2026-11-16 00:12 补正为准（覆盖 23:55「离开空椅保持上一版」）。

- **在岗工作（调转 180°）：** 人坐在桌子北侧（远处），面朝南（朝向镜头），在固定西南镜头下须能看清正面或四分之三侧面，而不是后背。在岗用椅转到桌北，椅背在人北侧（人身后）。显示器放在桌子南沿，屏幕朝向坐着的人（屏幕朝北）；镜头里常见近处是桌沿和显示器背面，人物在桌后抬头，脸可见。人、在岗用椅、显示器朝向一致：人面朝工作面/屏幕，不要背对桌子，也不要坐在椅子反面。手臂伸向南侧桌面。笔记本电脑若为在岗道具，屏幕朝向同样朝人。人物卡「在岗工作」、总图、房间特写（尤其 01 / 02 / 03）以及交互预留和开灯对照里的在岗坐姿均按此执行。

规定姿态（每张角色卡均须覆盖；场景总图用典型组合：视觉与动效在茶水间休息，其工位为离开；其余在岗）：

1. **在岗工作** — 坐在桌子北侧操作，面朝南，椅背在人身后，屏幕在桌南沿朝向人。
2. **空闲** — 在本房内站或坐，未埋头工作。
3. **离开** — 工位空着，空椅与在岗座位同一侧、同一朝向（桌北，椅背在北、座位朝南），辅以「离开」标记，人物走到门边或房外。
4. **待汇报** — 持文件，面向或站在老大办公室门口方向。
5. **茶水间闲逛 / 休息** — 走动端杯，或坐进沙发座位（臀在坐垫上、背靠椅背，不坐围挡）。

## 7. 姓名牌规则

- 只用岗位名：助理、构思家、素材管理、视觉与动效、工程、审查闸门、上架辅助、HR。
- 不加昵称，不加英文品牌。
- **位置：** 岗位姓名牌放在人物侧面（屏幕左侧、与头同高的留白处），锚在头侧并向外延伸，**不挡脸、不挡头、不挡关键剪影**，也不与邻座姓名牌、灯牌或「离开」标记严重重叠。
- 人物在场时只在人物旁留一块姓名牌。不再使用桌面上重复的岗位桌牌。
- 工位「离开」时，该人不在此房间，工位只留空椅与弱「离开」标记；「离开」不得与邻座姓名牌或灯牌叠字。姓名牌随人走。
- 人物卡上的姿态标签（默认站姿、在岗工作等）是图下说明，不是岗位姓名牌，放在画面留白，不要压到头上。
- 中文必须用正确简体后叠，不得使用生成图里的汉字。长名（「视觉与动效」「审查闸门」）不得裁切。

### 8.1 左右分栏窗口（极简纸白）

- 桌面画幅建议 1440–1920 宽（本稿为 1920×1080）。产品外壳是极简纸白、近乎无色的留白美学：大留白、几乎没有彩色强调、卡片轻、阴影极弱、信息靠层级而不是装饰。配色与字体气质取自用户提供的参考 `/workspace/可视化Bot协作管理后台-用户界面参考-纸白.png`，只借鉴配色与字体，不搬旅行清单的信息结构，不用「White白岩」「满当当」或熊猫作为品牌，窗口不是手机壳或 iOS 设备外框。
- 色板（允许极小修正，不要自行加回奶油黄或高饱和强调色）：页底 `#FEFEFE`；窗口壳 `#F4F2EE`；卡片与对话栏 `#FCFAF6`–`#FEFDF9`；细线 `#E7E5E1`；主标题墨色 `#2A2923`（展示字可到 `#171414`）；次要说明 `#87857E`–`#737269`；图标与实心图形 `#2B2B2B`。**模型视口内部**为近黑中性色 `#101010`，不是纸白，也不是偏蓝或偏棕。不要把浅色页面底 `#F3F1ED` 再当作模型区域的当前规格。不要重涂房间内部的木色、家具和人物。
- **不要**做成上一版偏暖的奶油窗口壳，不要把整个窗口改成深色 SaaS 主题（只有左侧模型容器是黑的），不要 8-bit，不要用中后台大表替代场景，不要画 macOS/iPhone 交通灯或设备皮。
- 字体：产品标题与关键大标题用 **Noto Serif CJK SC / 思源宋体**（SIL OFL），字重清楚够重，不要花哨装饰体。正文、对话气泡、辅助标签、工具条用 **Noto Sans CJK SC**。不要使用未核许可的商用字体。
- **左侧模型区域**占主要宽度，放入已确认的固定西南 2:1 等轴测办公室（界面合成为无灯效、近黑地面的新渲，布局与人物与定稿一致），用来看各岗位在做什么。模型区域是坐在纸白壳上的近黑圆角容器：左/右/上内缩 18px，底边内缩 70px（为工具条留出纸白条带），栏体半径 16px，四角都要在 1920×1080 总图上可辨，尤其靠对话栏的右上、右下和靠窗口的左上、左下；不要齐缝铺满左栏，也不要贴死窗口外缘。画布可平移、缩放，**不可自由旋转**；设计稿用静帧 + 极弱纸白工具条表示，工具条放在黑色容器下方的纸白壳上，不要做成深色控制台控件，不要没入黑底，也不要做成可交互产品。
- **右侧对话**是与「助理」的常驻界面，右栏约 360–480px 或约 28–32% 宽（本稿右栏为 480px）。默认就在同屏，不是点开才出现的临时浮层，也不是另开一页。顶栏写清这是与助理的对话（标题可用衬线），底部有输入。
- **对话记录列表是内缩的圆角卡片**（改稿 05）：坐在纸白壳（`#F4F2EE`）上，不要齐缝铺满右栏。四边空隙 18px，栏体半径 16px，略小于窗口外圈 18px，但必须在 1920×1080 总图上一眼可辨。四角都要圆，尤其靠画布的左上、左下须完整露出；卡片右边也不要贴死窗口外缘，以免被窗口 18px 蒙版切角。卡片底 `#FCFAF6`–`#FEFDF9`，细线 `#E7E5E1`，阴影极弱。气泡半径约 12px，输入框半径约 12px，与栏体协调，不要做成正圆。不要新做多会话/聊天记录列表页或会话切换栏。
- 聊天头像若需要，只用姓名、首字的低饱和墨色块（近 `#2B2B2B`）或极淡纸底 + 墨字。**不要**沿用高饱和海军蓝色块，不要粘贴任何现有 Bot 圆形头像，更不要把圆形头像贴到左侧轴测身体上。
- 可弱参考既有风格 7/8 的信息层级（少标签、让布局说话）。画布外围若有平移/缩放或极弱图例，必须克制、服从左右分栏与纸白外壳。

### 8.2 近黑模型视口、一点点环境光与不发光的建筑名牌（界面层）

- 模型容器内部是近黑地面。未创建空地用略浅于纯黑的深石板色，必须明显深于开灯房间，但仍读作黑地上的空地，不是浅色地基。「未创建」铭牌、房间名和关键人物仍须可读。
- **一点点环境光，过渡须自然：** 开灯房间可以向邻近的黑色地面晕染一点点暖色环境光，光来自室内的窗、门、落地灯和靠开口的暖色地面，不是沿整栋建筑描一圈。衰减必须柔和、有远近：近处稍可见，向外很快变弱，边缘溶进 `#101010`，不要一道分界线，也不要做成宽度均匀、边缘偏硬的外发光描边。靠近门、窗或暖地面的一侧可以稍明显；背光或远离开口的一侧应更弱、更短，甚至几乎没有。仍然克制，不要舞台追光，不要大面积雾气，不要把整幅画布洗成暖色。未创建空地不要带这圈暖光。环境光来自房间，不是来自名牌；名牌多边形不得作为光源，也不得再做成发光灯箱。
- **名牌不发光：** 办公室名仍与轴测建筑一体（门楣或西门侧招），总图可读，尺寸保持放大后的一档。不要做成发光体，不要溢光、光晕或牌面自发光。开灯房间的名牌是干净哑光牌面；关灯只用室内明暗、色温区分，灯牌两侧都不发光。未创建空地没有房间名牌，只用「未创建」地基铭牌。
- 默认工作界面里四间房都开灯且都有人（视觉与动效在茶水间，其 APP 工位为桌北空椅 +「离开」）。四间开灯房间保持室内暖亮，名牌保持干净可读，只把一点暖光晕到邻地。若需要对照关灯，另出静帧，不要把默认工作界面改成关灯办公室。室内吊灯、落地灯、窗户的房间光照可以保留。

### 8.3 点击助理与其他交互预留

- 点击场景里的助理，应落到右侧对话（聚焦或接上正在进行的聊天），**不要再弹一个打乱左右布局的独立聊天窗**。
- 点击其他岗位、派活后走过来、完工汇报仍只做预留注释（淡框、路径虚线和一句说明），不做成可点击产品。注释、淡框和路径不要挡住名牌字面、人物头部，也不要盖住左侧模型容器的圆角。
